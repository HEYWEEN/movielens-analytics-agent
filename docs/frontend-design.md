# 前端设计与会话约定

## 方向与使用场景

2026-11-11，用户选定米黄色背景与橙色强调的 Claude 风格。本页是面向课堂演示和桌面数据分析的工作台，首屏以用户问题、助手回答和对应模型结果为中心。按用户要求，本轮只检查桌面端。

## 视觉规则

| 角色 | 约定 |
| --- | --- |
| 画布 | `#faf9f5`，约占可见区域 65%–80% |
| 会话导航 | `#f0eee6`，比画布略深，导航宽 208–224 px |
| 结果与输入表面 | `#fffefa`，比画布稍亮；边界 `#e2dfd5` |
| 主文字与次文字 | `#292720` / `#736f65`，保持正文与注释的可读对比 |
| 操作强调 | `#c46545`，用于发送、选中页签、模型比较和少量图标，通常低于 5% |
| 语义颜色 | 成功用低饱和绿、异常用暗红，仅表达执行状态 |
| 中文文字 | 宋体；正文 16 px，控件 12–14 px，标题 18–30 px，关键数据 36–48 px |

对话内容最大宽度 880 px，默认收起右侧工作记录；展开时展示任务状态、产物及可折叠的质量指标；窄桌面窗口使用右侧浮层，保持对话区的宽度。卡片使用统一留白和轻边界，内部比较依靠对齐与字级。无背景渐变，群体图采用稳定类别颜色。动效服务于真实流式生成、工具状态和后台任务进度；减少动态效果的系统偏好会关闭循环动画。

## 关键组件

1. **对话消息**：每轮文字、工具调用和结果都属于同一条消息；用户输入与助手回答保持明确对齐。结果以完整宽度嵌入消息，继续提问时位置稳定。
2. **模型与群体对照**：算法名、主要概率或群体规模、评价指标按三层排列。算法参数与版本展开读取。两列保持相同对齐，未知 ID、历史不足等状态就地显示。
3. **降维结果**：维数变化、信息保留、成对散点图形成主次关系。图例与轴说明可读，方法和资源开销折叠展示。
4. **输入与任务选项**：统一输入表面、发送按钮和焦点状态；任务配置在输入区上方展开，具有关闭、Esc 和互斥参数状态。
5. **工作记录**：可展开、收起；包含真实任务状态和产物链接。质量指标默认折叠，保持主要对话的阅读空间。

## 会话与兼容

每条消息有唯一 ID。`analysis` 保存任务 ID、查询结果快照与当前页签；每个结果视图在独立闭包内渲染。报告与坐标按任务加载并缓存，不写入其他消息的视图。切换会话后失效的异步结果不会回写当前页面。

旧格式只保存最后一次结构化结果，迁移时将它放到最后一条助手消息；更早的回复文本继续保留。浏览器空间不足时显示保存提示。
