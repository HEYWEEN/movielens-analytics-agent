# 架构与跨迭代接入约定

## 当前形态

本项目保持模块化单体。网页与 API 在一个服务进程；迭代一清洗由本地 Python 或 Hadoop Streaming 执行，迭代二分析由独立的 Python 任务执行。SQLite 保存两轮任务状态，文件系统保存各轮产物。DeepSeek 负责自然语言理解、工具选择和基于工具结果的说明；指标与预测由确定性的已登记工具计算。

网页优先使用宋体（`Songti SC` / `SimSun`）。结果按概览、高分预测、用户分群和降维对照切换，优先展示本次问题对应的结果。主界面突出概率、群体规模、维数变化和图表；指标定义、训练期口径、抽样方式及版本信息放在可展开的说明中。组件使用统一的字级、留白和细分隔线，避免重复的说明文案与嵌套装饰框；页签通过下划线表示选中，键盘焦点使用轻背景提示。

## 核心边界

1. **Agent/HTTP** 把请求交给 DeepSeek 选择工具，返回任务状态和已核验结果；API Key 只在服务端环境变量中读取。模型未调用工具时不能声称具体预测、分数或群体。
   对话最多执行 6 轮模型调用、12 次工具调用；模型可先发现已有任务，再查询报告与具体用户。问候和方法讨论允许直接回复，空用户集合表示未指定筛选。流式路径将 DeepSeek SSE 的文本片段和工具参数片段重组，向网页发送 NDJSON 阶段、工具及文本增量事件；普通 JSON 对话接口同时保留。每轮模型生成开始时重置临时文本，工具参数不会当作回复展示；完整回答保存一次，中断内容明确标记为未完成。工具不可用时将原因交回模型解释，耗时任务在后台执行，不把提交状态当作完成。
2. **工具** 声明输入和输出类型。治理工具输出清洗数据与质量报告；迭代二的逻辑回归、决策树、KMeans、层次聚类、PCA、NMF 各自是可独立调用的工具。算法模块不依赖 HTTP 或模型提供商。
3. **执行适配** 负责本地或 Hadoop 作业及错误传播；不得在执行失败时发布成功状态。
4. **任务存储** 分别保存治理和分析任务的状态、阶段事件与失败原因；重启后将中断任务标为失败。当前单机一次只执行一个耗时任务。
5. **产物清单** 记录上游清单摘要、清洗数据版本、`T1/T2`、分析配置、模型版本和每个产物的 SHA-256。分析前核验迭代一清单；读取已发布模型或报告时再核验两轮清单与版本。文件名和任务完成状态本身不足以证明内容未变。

## 迭代二数据流

```text
网页对话 ──> DeepSeek tool calling ──> 已登记工具 ──> 治理/分析任务服务
                                                    │
迭代一 manifest + 清洗文件 ──核验──> 分类事件特征 ───┼──> 两个分类模型
                                     训练期用户画像 ─┼──> 两组用户群体
                                                    └──> 两种降维模型与坐标
                                            迭代二 report + models + profiles
                                            + clusters + coordinates + manifest
```

分类的训练行只读取该事件之前的评分；验证期、测试期和查询使用冻结的 `T1` 历史。训练期画像只使用 `timestamp <= T1` 的记录。分类参数和阈值由验证集确定，测试集仅作最终评价。聚类和降维基于同一份训练期 37 维画像；压缩空间与原空间的轮廓系数并非同一距离口径，报告同时保存压缩后标签在原空间的轮廓系数与 ARI。

## 后续迭代的接入步骤

第二轮已按单个分析任务发布模型、特征口径、用户画像、聚类、完整降维坐标与评价报告，并以统一清单记录上游任务 ID、输入版本、参数和摘要。用户修改群体数、目标维数或信息保留阈值时，必须创建新分析任务；不能把旧模型改名为新配置。

第三轮先构建和校验图谱，再让推荐、图挖掘、链接分析工具引用**同一个已校验图谱版本或其投影**。图谱产物需记录上游清洗数据及第二轮产物版本。图谱缺失、校验失败或版本不一致时，工具拒绝运行。

未来增加工具时，应补齐：输入契约、版本检查、状态与失败语义、输出文件摘要、验证规则和最小集成测试。两轮目前各自发布清单，并通过迭代二清单中的上游摘要连接；第三轮应沿用这条依赖链，不应只根据目录名读取画像。

## 当前限制

Hadoop Streaming 把所有记录送到一个 reducer，适合课程数据规模但不具备横向扩展性。分析模型也在单机训练。任务执行线程和 SQLite 都运行在单服务进程内，适合单机演示；若需要多实例或可靠队列，应先将任务执行与 API 分离，并明确幂等和恢复策略。聚类是训练期画像的描述性划分，当前轮廓系数较低，不能把群体当作稳定的用户属性。2026-10-19 已验证真实 DeepSeek 对话、报告读取、预测和自然语言创建分析任务；模型解释仍需结合工具证据审阅，不保证每条推论都正确。
